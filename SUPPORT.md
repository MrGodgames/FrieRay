# Support

For general bugs and feature requests, use GitHub Issues:

- https://github.com/MrGodgames/FrieRay/issues

Before opening an issue:

- check that you are using the latest release
- search existing issues
- remove private connection details from logs and screenshots

Do not share real subscription URLs, server UUIDs, passwords, access tokens, generated Xray configs, or provider account data in public issues.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
